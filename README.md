# Power BI Canteen Dashboard

## Project Overview
This project is a Power BI dashboard assignment designed to demonstrate business intelligence and data visualization skills through canteen-related data.

## Project File
- `POWER BI CANTEEN DASHBOARD ASSIGNMENT.pbix` — Power BI Desktop project file.

## Tools & Technologies
- Microsoft Power BI Desktop
- Data Visualization
- Business Intelligence
- Interactive Dashboard Reporting

## Key Objectives
- Present canteen data in an interactive dashboard.
- Make information easier to understand through visualizations.
- Support data-driven analysis and reporting.

## How to View the Project
1. Download the `.pbix` file from this repository.
2. Open it using Microsoft Power BI Desktop.
3. Explore the available report pages, charts, and interactive filters.

## Author
Created as a Power BI dashboard assignment and learning project.
